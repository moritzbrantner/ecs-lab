Comparison method

Optimize implementations, not semantics

The lab separates the question “what should this workload mean?” from “which storage strategy executes it best?” so faster candidates can be checked mechanically.

  1. 01Workload

    Generate deterministic entity/component operations and seeds.

  2. 02Reference

    Replay them in the simple BTreeMap-backed semantic oracle.

  3. 03Candidate

    Replay the same operations in sparse-set, archetype, or future designs.

  4. 04Parity

    Compare snapshots before considering performance evidence.

  5. 05Measure

    Benchmark named scenarios with reproducible environment metadata.
