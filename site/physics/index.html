Ownership boundary

A richer scene still has one simulation authority

The Wasm adapter exports authoritative 3D positions, collider extents, fixed/dynamic metadata, materials, and the canonical collision-pair bitset. Mouse input changes only the camera. The render loop interpolates only between consecutive Rust frames. At every integer physics step, both the scene and the optional WebGPU verifier return to the exact Rust state.
