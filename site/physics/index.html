3D physics demo

Forty-eight dynamic bodies move on all three axes inside a fixed floor, ceiling, side, front, and back room. Rust advances the authoritative simulation at 60 fixed solver steps per second, sweeps fixed and moving AABB pairs through X/Y/Z/time inside every 1/60-second frame, collects every pair and tied axis at the earliest exact impact time, and resolves that contact set deterministically before the next frame. A separate rotation-aware dice fixture now demonstrates Rust-owned orientation, off-center contact impulses, and angular velocity without pretending the existing AABB room is already an oriented-box solver.

Angular rigid-body slice

A tilted box acquires real spin from an off-center floor impact

This fixture starts with a tilted cuboid and zero angular velocity. Every 1/60-second step is computed in Rust. The actual oriented corners determine which vertex or edge reaches the plane; the resulting contact impulse acts away from the center of mass and therefore changes angular velocity through the cuboid inertia tensor. The browser draws the eight exact vertices exported by that same Rust collision geometry rather than rotating a decorative cube itself.

Ownership boundary

Every displayed frame is a Rust physics state

Rust owns the 60 Hz fixed-step progression, relative-motion swept pair tests, exact fractional TOI comparison inside each frame, global earliest contact-set collection, bounded coupled response, deterministic fixed-point quantization, angular orientation integration, and the rotation-aware dice contact response. The Wasm adapter normalizes coordinates only for display. Mouse input changes the room camera; playback and manual frame selection never integrate velocity, resolve contacts, rotate collision geometry, or invent intermediate physics states.
