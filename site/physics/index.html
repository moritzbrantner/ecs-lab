Ownership boundary

Continuous collision time belongs to Rust, not the visualization

Rust owns swept fixed-body candidate tests, exact fractional TOI ordering, bounded impact iteration, response, and ECS writes. The Wasm adapter exports authoritative integer frames. Mouse input changes only the camera; step stride and the timeline matrix select or visualize those frames and never integrate velocity, resolve contacts, or change solver time.
