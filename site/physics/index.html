Three bodies move through depth inside a closed Rust-owned room

Body A is light and fully bouncy, B uses medium restitution and friction, and C is heavier, inelastic, and maximally frictional. They move on all three axes inside fixed floor, ceiling, side, front, and back slabs. The discrete physics state remains deterministic; only the rendered transform is interpolated for smoother motion.

Ownership boundary

Smooth rendering never becomes a second simulation

The Wasm adapter exports authoritative 3D positions, collider extents, fixed/dynamic metadata, materials, and the canonical collision-pair bitset. The render loop interpolates only between consecutive Rust frames. At every integer physics step, both the scene and the optional WebGPU verifier return to the exact Rust state.
