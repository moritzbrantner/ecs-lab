Ownership boundary

Time can become another view dimension without becoming another simulation

The Wasm adapter exports authoritative 3D positions, collider extents, fixed/dynamic metadata, materials, and the canonical collision-pair bitset. Mouse input changes only the camera. Step stride changes only which existing frames are selected, while the time matrix independently reads the same deterministic Rust/Wasm timeline. Neither feature integrates velocity, resolves contacts, or changes solver dt in JavaScript.
