Ownership boundary

The browser is a demo adapter, not a second physics engine

The Wasm adapter asks the Rust scenario for a deterministic frame, including body positions, collider extents, fixed/dynamic metadata, materials, and the canonical collision-pair bitset. JavaScript only draws that state. When enabled, WebGPU is differential broad-phase evidence over those final AABBs and is rejected on any parity mismatch.
