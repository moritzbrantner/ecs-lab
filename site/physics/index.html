Ownership boundary

The browser is a demo adapter, not a second physics engine

Each preset is synchronized into the Wasm adapter using ordinary entity inputs. Rust replays the world, performs deterministic material physics, and returns the final positions plus the canonical collision-pair bitset. The page visualizes that state. When enabled, WebGPU is only differential evidence over those final AABBs.
